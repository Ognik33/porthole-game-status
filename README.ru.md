# Статус игры - дополнение для Porthole

[English](README.md)

Показывает в лобби [Porthole](https://store.steampowered.com/app/4963920) плашки открытых игровых миров: версию, название мира и онлайн. Друзья, у которых тоже стоит дополнение, видят ваши миры у себя и могут одной кнопкой скопировать адрес для подключения.

![Плашки в списке участников и вкладка «Статус игры»](docs/screenshot.png)

## Что умеет

- Сам находит миры Minecraft Java, открытые через «Открыть для сети», - от 1.3 до 26.x и снапшотов. Понимает окна лаунчеров (MultiMC, Prism и др.) и `java.exe`: такие порты сначала проверяются и показываются, только если это действительно Minecraft.
- Плашка в списке участников: `Minecraft: 26.3 · Survival · 2/8`. Несколько миров одной игры - одна плашка, которая показывает их по очереди (`1/3 ▸ …`).
- Вкладка «Статус игры»: по кнопке на мир, по нажатию раскрываются хост, игроки и порт, кнопки «Скопировать порт» и «Скопировать адрес».
- Миры друзей с кнопкой «Скопировать адрес 10.99.x.x:порт» для «Прямого подключения» через виртуальную LAN Porthole.
- Настройки: перелистывание миров, показ игроков, **скрытие имён для стримов**.
- Интерфейс на русском, украинском, английском и немецком.

## Установка

1. Скачайте `game-status-<версия>.paddon` из [Releases](../../releases).
2. **Выйдите из лобби** (в лобби дополнения менять нельзя).
3. Porthole → Настройки → Дополнения → «Установить из файла» или перетащите файл в окно.
4. Включите дополнение, создайте лобби и откройте мир для сети.

Обновление - установка новой версии поверх старой. Друзьям нужна совместимая версия: 0.2.x не видит 0.1.x.

## Какие разрешения просит и зачем

| Разрешение | Зачем |
|---|---|
| `ui` | плашки и вкладка |
| `identity`, `roster` | кто вы и кто в лобби - чтобы повесить плашку нужному человеку |
| `net` | обмен статусом миров с этим же дополнением у друзей |
| `system` | узнать, какие программы слушают порты (`on_listening`), и отправлять команды своему нативному помощнику на `127.0.0.1` |
| `run_helper` + `natives` | запустить `game_probe.dll`: опрос миров, адрес адаптера виртуальной LAN, копирование в буфер обмена |

Прав администратора не нужно. Дополнение не выходит в интернет и не читает ваши файлы. `game_probe` подключается только к портам на вашем же ПК и делает тот же запрос, что список серверов в самой игре. Его порт для команд слушает только `127.0.0.1` и принимает команды лишь со случайным токеном, который знает дополнение.

## Как это работает

- **Luau** (`src/*.luau`, при сборке склеивается в один `main.luau`) находит кандидатов в `on_listening` по профилям игр, отправляет помощнику желаемый список миров, рисует интерфейс и обменивается состоянием с друзьями.
- **game_probe** (`native/game_probe.c`, C + [cJSON](https://github.com/DaveGamble/cJSON)) - один процесс на сессию. По миру на поток: зависший мир не тормозит остальные. Команды принимает со случайным токеном, события пишет строками в stdout. Для Minecraft понимает три поколения протокола и миры, которые слушают только адрес домашней сети (старые версии).
- **Протокол между участниками `gs3`**: версия схемы, только нужные поля, порядковый номер и эпоха, подтверждение раз в 30 секунд, протухание через 90, лимит 4096 байт на сообщение, проверка всех входящих данных.
- **Профили игр** - `games.toml`: подпись, признаки окна или процесса и модуль опроса. Новая игра на уже поддерживаемом протоколе - это новая запись в файле.

## Сборка и тесты

Нужны `mingw-w64`, `python3`, `zip` (Linux или WSL), для Luau-тестов - [`luau`](https://github.com/luau-lang/luau/releases):

```bash
sudo apt install gcc-mingw-w64-x86-64 zip python3
./tools/build.sh   # -> dist/game-status-<версия>.paddon, dist/game_probe_cli.exe
./tools/test.sh    # проба против поддельных серверов, протокол агента, Luau-тесты
```

Сборка воспроизводимая: `.paddon` из Releases (его собирает GitHub Actions из этого кода) побитово совпадает с вашей локальной сборкой тем же компилятором.

`game_probe_cli.exe` - та же проба отдельной программой для диагностики, например `game_probe_cli.exe --debug --status minecraft 51807`.

## Совместимость и ограничения

- Проверено на Porthole 3.0.2, API дополнений версии 1. SeStudio называет API нестабильным: после обновления Porthole может понадобиться правка.
- Только Windows (Linux - в планах).
- Пока только Minecraft Java. Другие игры - в планах.
- Плашки видят только участники, у которых дополнение установлено.

## Планы

- Точное обнаружение LAN-миров по их объявлениям в сети - автоматически, если у Porthole уже есть разрешение брандмауэра.
- Игры на Valve A2S (Valheim, Rust и др.).
