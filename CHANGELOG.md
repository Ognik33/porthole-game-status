## 0.2.0
Переработка архитектуры. Несовместимо с 0.1.x: обновиться нужно всем участникам.

- **Один нативный агент на сессию** (`game_probe --agent`) вместо процесса на каждый мир:
  поток на мир, команды через `tcp_send` на 127.0.0.1 со случайным токеном, сверка желаемого
  состояния по порядковому номеру. Падение агента — перезапуск с нарастающей паузой.
- **Протокол `gs3`**: версия схемы (новые поля не ломают старые копии), эпоха и порядковый номер,
  подтверждение раз в 30 с, протухание через 90 с, лимит 4096 байт, флаг доступности по LAN
  вычисляет хост. Новичку состояние отправляется лично.
- **Исправлено:** ушедший из лобби друг оставался в «Мирах друзей».
- **Проверка всех входящих данных**: адреса, порты, длины строк, UTF-8.
- **Плашки обновляются только при изменении.**
- **Настройки**: перелистывание миров, показ игроков, скрытие имён для стримов.
- **Переводы** штатным механизмом Porthole (`lang/*.toml`): русский, украинский, английский, немецкий.
- **Профили игр в `games.toml`**; ядро не знает о конкретных играх.
- Исходники Luau — модули в `src/`, склеиваются при сборке. Тесты: проба против поддельных серверов,
  протокол агента, юнит-тесты и сценарии Luau. Воспроизводимая сборка.
- game_probe 0.3.0.

## 0.1.9
- Адрес виртуальной LAN теперь отслеживает один наблюдатель на всю сессию
  (`game_probe --lan-watch`): адрес появляется у друзей не позже чем через ~3 секунды после того,
  как LAN поднялась, и обновляется при переподключении. Раньше были разовые проверки по
  расписанию, и у участника, к которому LAN приходит позже хоста, кнопка адреса могла не
  появляться до минуты.
- game_probe 0.2.6.

## 0.1.8
- Адрес в виртуальной LAN Porthole: проба читает адрес адаптера `porthole0` (`--lan-addr`),
  хост отправляет его друзьям вместе со статусом мира.
- У друзей под твоим миром — кнопка «Скопировать адрес 10.99.x.x:порт» для «Прямого подключения».
  У себя — то же рядом с «Скопировать порт».
- Миры, которые слушают только адрес домашней сети (Minecraft 1.3), помечены «только домашняя
  сеть»: через виртуальную LAN к ним не подключиться. Проба сообщает, на каком адресе ответил мир
  (поле `addr`).
- game_probe 0.2.5 (теперь использует iphlpapi).

## 0.1.7

  Буфер обмена заполняет game_probe (`--clip`), у Luau своего доступа к нему нет.
- game_probe 0.2.4.

## 0.1.6
- Плашка с несколькими мирами — карусель: миры сменяются раз в ~4 секунды, индикатор в начале
  (`1/3 ▸ 26.3 · Survival · 1/8`), чтобы его не обрезало справа. Один мир — без индикатора.
- Вкладка — раскрывающийся список: по кнопке на мир (`26.3 · Survival · 1/8 ▸`), по нажатию
  открывается табличка с хостом, игроками и портом. Единственный мир раскрыт сразу.
  Старые миры помечены меткой «старый протокол».

## 0.1.5
- Minecraft 1.3.x (и, вероятно, другие старые версии) открывает LAN-мир только на сетевом
  адресе ПК (например, 192.168.0.x), а не на 127.0.0.1. Проба теперь пробует адреса ПК, если
  127.0.0.1 отказывает.
- Такие серверы молча сбрасывают повторное подключение с того же адреса в течение ~5 секунд.
  Через сетевой адрес проба делает одну попытку за опрос (legacy первым) и опрашивает не чаще
  раза в 7 секунд.
- Мир, который ещё ни разу не ответил, получает три попытки, прежде чем считаться «не отвечает»
  (или, для окон лаунчеров и java.exe, — не Minecraft). Первый ответ старой версии приходит
  примерно через 7–15 секунд.
- game_probe 0.2.3: `--debug` печатает, что уходит и приходит по сети; `--try-addr` для тестов.
  Есть консольная сборка для диагностики (`tools/build.sh` собирает `game_probe_cli.exe`).

## 0.1.4
